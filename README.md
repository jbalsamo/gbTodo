# gbTodo

A small React todo app: add tasks, mark them complete, and filter to what is still open.

## Stack

React 19, Vite, TypeScript, Tailwind CSS, Vitest, Testing Library.

## Scripts

```bash
npm install
npm run dev
npm test
npm run build
```

`npm test` runs `vitest run`.

## Features

- Add todos with Enter or the Add button
- Checkbox labeled by the todo text to mark done / undone
- Filter: All vs Active
- No delete, edit, persistence, or backend
